# AND Portfolio Project Conventions

- Keep apartment project naming consistent across the Projects card, detail-page hero, metadata, and project data. Include the full regional prefix used by neighboring projects; for Cheongna projects, use `인천 청라` before the apartment name.
- Every portfolio detail page must include the shared `Project Information` section at the bottom. Do not set `hideProjectInformation` unless the user explicitly requests an exception.
- Keep proposal work labeled as `Design Proposal`, `Rendering Proposal`, or `Design Proposal / Rendering` as appropriate. Never describe proposal images as completed construction.
- Reuse the established typography, section structure, and restrained editorial tone of the existing Lynn Strauss and Hoban 4 project pages.
